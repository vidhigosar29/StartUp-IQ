Beyond central schemes

State & UT startup schemes

Every Indian state and union territory runs its own startup policy on top of the central schemes — seed grants, sustenance allowances, patent and marketing reimbursements, SGST refunds, lease-rental and power subsidies, and preferential public procurement. State benefits stack with central ones. This index gathers the concrete schemes and incentives each state offers, straight from its official startup policy — kept separate from the central playbook.

State schemes

State incentives stack with central schemes — a startup can draw on both. Amounts, windows and eligibility come from each state's official startup policy and change often; blank fields are left blank rather than guessed. Always confirm on the state portal before applying.
